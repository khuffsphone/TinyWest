## Environment note (not a code issue)

The QA tools (`playtest.mjs`, `qa2.mjs`, `qa3.mjs`) import `playwright`, but the repo
has no `package.json`/lockfile and no local `node_modules` — they only run because
`playwright` happens to be installed globally in this container. A fresh checkout in
an environment without a global Playwright install would fail these three scripts
immediately (`ERR_MODULE_NOT_FOUND`). `build.mjs` has no such dependency and always
works. Worth an owner decision on whether to commit a `package.json` pinning
`playwright` so QA is reproducible outside this container — not done here since it's
a build-process change, not requested.
